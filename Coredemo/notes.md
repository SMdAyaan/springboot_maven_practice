Dependency Injection (DI) is a design pattern where an object receives its dependencies from an external source rather 
than creating them itself, promoting loose coupling and easier testing.

Don't create your own dependencies, get them.

IoC (Inversion of Control) is a design principle where the framework manages object creation and dependencies, 
rather than the objects managing themselves.

Spring has an IoC container which automates the process of Dependency Injection
IoC container:
1. creates obj
2. Manage obj
3. Connects obj together

Beans are the objects used by our Spring Framework.
Two ways to configure Beans:
1. Annotation Based
2. XML Configuration based
